\section{The Problem: Paper Registers \& Delayed Escalation}
India's 1M+ Accredited Social Health Activists (\textbf{ASHAs}) conduct doorstep maternal and general health visits across rural villages, often operating on basic 2G feature phones in high-noise environments. Vital readings (blood pressure, hemoglobin, gestational age, danger signs) are written into paper registers and batch-entered days later at the Primary Health Centre (\textbf{PHC}). By the time severe preeclampsia ($\text{BP} \ge 160/110\text{ mmHg}$) or critical anemia ($\text{Hb} < 5.0\text{ g/dL}$) is reviewed by a Medical Officer, the window for early intervention has often closed.

\section{The Solution: ASHA-Vani}
Built from the ground up for \textbf{Pan-India maternal health}, \textbf{ASHA-Vani} turns any basic feature phone or PSTN line into a multilingual, voice-verified clinical register and early-warning system. An ASHA worker dials in (via Exotel PSTN or the built-in 8\,kHz Nokia simulator) and speaks naturally in \textbf{Hindi, Tamil, or Telugu}—backed by a drop-in locale architecture ready to scale across \textbf{all 10 Gnani Prisma Indian languages} (\texttt{hi-IN}, \texttt{en-IN}, \texttt{ta-IN}, \texttt{te-IN}, \texttt{kn-IN}, \texttt{ml-IN}, \texttt{mr-IN}, \texttt{bn-IN}, \texttt{gu-IN}, \texttt{pa-IN}) with zero changes to core clinical logic:
\begin{itemize}
  \item \textbf{Automatic Worker \& Language Routing:} Caller ID lookup against Supabase \texttt{asha\_workers} / \texttt{asha\_worker\_phones} (with offline JSON fallback) greets known ASHAs in their native language immediately; unknown callers get a bilingual greeting, \textbf{Prisma \texttt{indic-auto}} + script detection, and \texttt{pending\_phone\_links} queueing, plus anytime mid-call switching via \textbf{keypad \texttt{9}}.
  \item \textbf{Multilingual STT \& English Register Normalization:} Streams 8\,kHz audio through \textbf{Gnani Prisma STT} across regional languages and normalizes all patient/village names to \textbf{English Roman Title Case} for PHC Medical Officers.
  \item \textbf{Stateful Extraction \& Deterministic Triage:} Redacts phone/Aadhaar PII pre-LLM, extracts fields into a \textbf{7-step LangGraph intake} (\texttt{CallState}) via \textbf{Gnani Evon v3.3 (\texttt{30B-A3B})} with \texttt{enable\_thinking=False} (Groq Llama 3.3 / regex failover), enforces \textbf{hard physiological bounds}, and runs \textbf{deterministic rules (\texttt{R1--R8})}.
  \item \textbf{Native Readback \& PHC Dispatch:} Speaks a \textbf{digit-by-digit confirm-back} in the active language via \textbf{Gnani Timbre v2.5 TTS}, marks the record \texttt{VERIFIED} on confirmation, and streams updates for 1-click dispatch (\texttt{108}, ANM, or Home Follow-up).
\end{itemize}

\section{Core Gnani.ai Voice Integration}
\begin{itemize}
  \item \textbf{8\,kHz Telephony Conditioning (\texttt{voice/audio.py}):} Resamples to 8\,kHz mono PCM16, band-pass filters ($300\text{--}3400\text{ Hz}$), $\mu$-law compands, and slices into exact \textbf{1024-byte (64\,ms)} frames with calibrated SNR noise injection ($15\text{ dB}$ and $5\text{ dB}$).
  \item \textbf{Gnani Prisma Streaming STT (\texttt{voice/stt.py}):} Bi-directional WebSocket streaming with \texttt{indic-auto} detection, dual End-of-Utterance (\textbf{EOU}) detection ($\sim 1.2\text{ s}$ silence or trailing \texttt{``over''}), and DTMF keypad fallback (\texttt{0--9, *, \#}).
  \item \textbf{Gnani Timbre v2.5 TTS (\texttt{voice/tts.py}):} Synthesizes native prompts at 8\,kHz PCM/WAV (\texttt{Poorvi}/\texttt{Nalini} Hindi, \texttt{Asmita} Tamil, \texttt{Suhana} Telugu) using an in-memory fixed-script cache for zero redundant latency or API cost.
  \item \textbf{Half-Duplex Anti-Echo Gate (\texttt{voice/session.py}):} Drops incoming mic frames while TTS plays plus a strict \textbf{200\,ms acoustic tail guard}, preventing loudspeaker echo loops.
\end{itemize}

\section{Clinical Safety Architecture}
ASHA-Vani is strictly a \textbf{decision-support and early-warning pipeline}, never an autonomous diagnosis engine:
\begin{enumerate}[leftmargin=12pt,itemsep=1pt,topsep=1pt]
  \item \textbf{The LLM Extracts; Deterministic Code Decides:} The language model only populates candidate slots (\texttt{ExtractedVisit}); risk classification is 100\% rule-based (\texttt{triage.py}).
  \item \textbf{Refuse to Guess (Hard/Soft Range Guards):} Impossible ASR/speech artifacts (e.g., $\text{BP } 420/110\text{ mmHg}$, $\text{Hb } 28\text{ g/dL}$, or $\text{systolic} \le \text{diastolic}$) are rejected as \texttt{ERROR}, cleared to \texttt{None}, and routed to a targeted spoken repeat prompt—without masking co-occurring critical danger signs.
  \item \textbf{Alert Early, Commit Late:} High-risk intakes appear on the PHC console immediately on Turn 1 marked \texttt{UNVERIFIED (In Call)} so officers have early situational awareness, flipping to \texttt{VERIFIED} only after the ASHA confirms the spoken readback (\emph{``Haan, sahi hai''}).
\end{enumerate}
